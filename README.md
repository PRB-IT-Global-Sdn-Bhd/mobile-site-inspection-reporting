# Mobile App — Site Inspection & Reporting App

> **PRB IT Global Sdn Bhd** | Custom Software for SME Engineering & Construction Clients (Malaysia)

## Overview

A cross-platform **Mobile Application** enabling site engineers, safety officers, and inspectors to conduct structured site inspections, capture evidence, and generate professional reports — all from their smartphones, even in offline environments.

## Key Features

| Feature | Description |
|---|---|
| Inspection Checklists | Configurable digital checklists (safety, quality, progress) |
| Photo & Video Capture | Geo-tagged media with annotations |
| Offline Mode | Full functionality without internet, auto-sync when connected |
| Report Generation | Automated PDF reports with signatures and timestamps |
| Non-Conformance Reports | Raise, assign, and track NCRs in real time |
| Push Notifications | Instant alerts for critical findings or deadlines |
| Integration | Syncs with ERP and compliance dashboard |

## Technology Stack

- **Framework:** React Native (Expo) / Flutter
- **Backend:** Node.js / Python FastAPI
- **Database:** SQLite (offline) + PostgreSQL (cloud)
- **Storage:** AWS S3 for media files
- **Platform:** iOS & Android

## Target Users

Site engineers, safety officers (SHO), quality inspectors, and project supervisors.

## Getting Started

```bash
git clone https://github.com/PRB-IT-Global-Sdn-Bhd/mobile-site-inspection-reporting.git
cd mobile-site-inspection-reporting
npm install
npx expo start
```
